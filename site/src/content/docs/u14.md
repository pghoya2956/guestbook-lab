메뉴마다 안내 문서가 있습니다. [메뉴 고르기](/guestbook-lab/menu/)에서 하나를 고르고 문서의 완료 기준까지 해 봅니다.

## 새로고침할 때마다 저장소 표시가 바뀝니다

:::caution[고칠 것]
로드 밸런서 뒤 서버 두 대 중 한 대만 바꿨습니다.

두 대 모두 같은 설정으로 바꾸고 각각 다시 시작합니다.

```bash
sudo systemctl restart guestbook
```
:::

## 정책에 넣을 계정 ID 에 하이픈이 섞여 있습니다

:::caution[고칠 것]
콘솔 오른쪽 위에는 계정 ID 가 네 자리씩 하이픈으로 끊겨 보입니다.

정책에는 하이픈을 빼고 숫자만 이어 붙입니다.
:::

## DB 만들기가 권한 오류로 거부됩니다

:::caution[고칠 것]
수업 계정에서 되는 DB 값을 벗어났습니다. 처음 골라진 엔진은 Aurora PostgreSQL 입니다.

「전체 구성」, 엔진 **MySQL**, 템플릿 「샌드박스」를 고릅니다. [수업 계정에서 되는 값](/guestbook-lab/basics/values/)도 봅니다.
:::

## DB 가 몇 분째 「생성 중」입니다

:::tip[정상입니다]{icon="approve-check-circle"}
5분 넘게 걸릴 수 있습니다. 기다리는 동안 메뉴 문서의 다음 단계를 진행합니다.
:::

## Chrome 이 비밀번호를 저장할지 묻습니다

:::caution[고칠 것]
저장하지 않습니다(「사용 안함」). 공용 PC 에 DB 비밀번호가 남습니다.
:::

:::note[그래도 안 되면]
화면을 그대로 두고 손을 드세요. 좌석 번호, 단원 번호, 화면의 오류 문구를 말해 주세요.
:::
