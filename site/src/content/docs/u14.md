## 따라 하기

### 메뉴에서 1~2개를 골라 내 앱에 붙이세요

| 개선 메뉴 | 쓰는 서비스 | 완료 기준 |
|---|---|---|
| [방명록에 이미지 첨부](/guestbook-lab/menu/1-image/) | S3, IAM 역할 | 이미지가 페이지에 보임 |
| [저장소를 데이터베이스로](/guestbook-lab/menu/2-dynamodb/) | DynamoDB | 글이 테이블에 쌓임 |
| [기능 하나를 서버리스로](/guestbook-lab/menu/3-serverless/) | Lambda, API Gateway | 분리한 주소가 응답함 |
| [트래픽 두 배 버티기](/guestbook-lab/menu/4-scaling/) | 오토 스케일링 | 부하를 걸면 서버가 늘어남 |
| [장애 알림 받기](/guestbook-lab/menu/5-alarm/) | CloudWatch 알람 | 오류를 일으키면 알람이 울림 |
| [저장소를 MySQL로 (심화)](/guestbook-lab/menu/6-rds/) | RDS, Parameter Store | 글이 DB에 쌓임 |
| [VPC를 코드로 (심화)](/guestbook-lab/menu/7-terraform/) | Terraform | apply로 같은 구조가 생김 |

메뉴마다 실습 런북 [메뉴 고르기](/guestbook-lab/menu/)에 안내 문서가 있습니다. 심화 두 메뉴는 2학년과 빨리 끝낸 학생용입니다.

### 그리고, 만들고, 확인합니다

1. **고르고 그리기** 바뀔 구조도를 먼저
2. **만들기** 안내 문서를 따라
3. **완료 확인** 표의 완료 기준대로
4. **강사 리뷰** 진행 확인 화면으로 반 전체를 함께 봅니다

**막히면** 오류 메시지를 읽고, 실습 런북을 보고, 그래도 안 되면 손을 드세요

**빨리 끝나면** 두 번째 메뉴, 또는 내 프로젝트를 올려 보기

## 막혔을 때

메뉴마다 안내 문서가 있습니다. [메뉴 고르기](/guestbook-lab/menu/)에서 하나를 고르고 문서의 완료 기준까지 해 봅니다.

### 새로고침할 때마다 저장소 표시가 바뀝니다

:::caution[고칠 것]
로드 밸런서 뒤 서버 두 대 중 한 대만 바꿨습니다.

두 대 모두 같은 설정으로 바꾸고 각각 다시 시작합니다.

```bash
# 앱을 다시 켜서 바뀐 설정을 읽게 합니다
sudo systemctl restart guestbook
```
:::

### 정책에 넣을 계정 ID 에 하이픈이 섞여 있습니다

:::caution[고칠 것]
콘솔 오른쪽 위에는 계정 ID 가 네 자리씩 하이픈으로 끊겨 보입니다.

정책에는 하이픈을 빼고 숫자만 이어 붙입니다.
:::

### DB 만들기가 권한 오류로 거부됩니다

:::caution[고칠 것]
수업 계정에서 되는 DB 값을 벗어났습니다. 처음 골라진 엔진은 Aurora PostgreSQL 입니다.

「전체 구성」, 엔진 **MySQL**, 템플릿 「샌드박스」를 고릅니다. [수업 계정에서 되는 값](/guestbook-lab/basics/values/)도 봅니다. <a href="https://ap-northeast-2.console.aws.amazon.com/rds/home?region=ap-northeast-2#launch-dbinstance:" target="_blank" rel="noopener">콘솔 열기 ↗</a>
:::

### DB 가 몇 분째 「생성 중」입니다

:::tip[정상입니다]{icon="approve-check-circle"}
5분 넘게 걸릴 수 있습니다. 기다리는 동안 [메뉴 문서](/guestbook-lab/menu/6-rds/)의 다음 단계를 진행합니다.
:::

### Chrome 이 비밀번호를 저장할지 묻습니다

:::caution[고칠 것]
저장하지 않습니다(「사용 안함」). 공용 PC 에 DB 비밀번호가 남습니다.
:::

:::note[그래도 안 되면]
화면을 그대로 두고 손을 드세요. 좌석 번호, 단원 번호, 화면의 오류 문구를 말해 주세요.
:::
