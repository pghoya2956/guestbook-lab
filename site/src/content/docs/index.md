지금 하는 단원을 누르세요. 단원 페이지 위쪽 「따라 하기」에 실습 순서와 복사할 명령이 있고, 아래쪽 「막혔을 때」에 화면별 고치는 법이 있습니다. 오류 문구는 위의 검색에 넣어도 됩니다.

## 1일차

- [1단원 콘솔 로그인](u1/): 첫 로그인, MFA 등록, 새 비밀번호
- [3단원 일부러 거부당하기](u3/): 막히는 요청으로 권한 읽기, CloudShell
- [4단원 EC2 시작과 Session Manager](u4/): 서버를 켜고 브라우저로 접속
- [5단원 앱 배포와 서비스 등록](u5/): 급식 리뷰 앱 실행, 재부팅해도 살아 있게
- [6단원 보안 그룹으로 공개](u6/): 80 포트를 열고 내 브라우저로 급식 리뷰 앱 열기
- [9단원 IAM 역할로 S3 읽기](u9/): 키 없이 S3 를 읽는 서버
- [8단원 퇴실 전 서버 중지](u8/): 하루 회고, 서버 중지

## 2일차

- [10단원 VPC 직접 만들기](u10/): VPC, 서브넷, 인터넷 게이트웨이, 라우팅 테이블
- [11단원 시작 템플릿으로 새 VPC 에 서버](u11/): 켜자마자 앱이 뜨는 서버
- [12단원 로드 밸런서와 오토 스케일링](u12/): 서버 두 대, 일부러 중지해 보기
- [13단원 서버리스 맛보기](u13/): Lambda 로 「급식실 한마디」 함수
- [14단원 미니 프로젝트](u14/): 과제를 골라 내 급식 리뷰 앱에 붙이기
- [15단원 정리](u15/): 만든 순서의 반대로 지우기

## 처음 오면

- [리전과 되는 값](basics/values/): 서울 리전, 수업 계정에서 되는 값, 수업에서 쓰는 이름
- [오류 읽는 법](basics/errors/): explicit deny, 권한 미부여, http 주소가 안 열릴 때
- [무시해도 되는 화면](basics/ignore/): 말풍선, 계정 차단 안내, 요금 화면
- [미니 프로젝트 과제](menu/): 과제 여섯 가지와 완료 기준
- [수업이 끝난 뒤](after/): 수업 덱, 내 계정으로 다시 해 볼 때 달라지는 것

## 막혔을 때

1. 단원 페이지 아래쪽 「막혔을 때」 상자 가운데 내 화면과 같은 것을 찾습니다.

2. 5분쯤 해 봐도 안 되면 화면을 그대로 두고 손을 듭니다. 오류 메시지는 지우지 마세요. 오류 메시지가 가장 좋은 단서입니다.

3. 손을 들면 좌석 번호, 단원 번호, 화면의 오류 문구를 말해 주세요.

:::tip[늦어도 괜찮습니다]
막힌 단계는 강사가 완성 상태로 맞춰 줍니다. 다음 단원은 모두 같이 시작합니다.
:::
