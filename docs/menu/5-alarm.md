# 메뉴 5. 장애 알림 받기

쓰는 서비스: CloudWatch 알람 · 완료 기준: 장애를 일으키면 알람 상태가 ALARM 으로 바뀐다

## 바뀌는 구조

사람이 화면을 계속 보지 않아도, 서비스가 실패하기 시작하면 CloudWatch가 먼저 알아챕니다.

## 만들 것

1. CloudWatch → 알람 생성 → 지표 선택: ApplicationELB → 로드 밸런서별 → `HTTPCode_Target_5XX_Count`
2. 통계 합계, 기간 1분, 조건 5 초과, 데이터 포인트 1/1
3. 알림 대상은 만들지 않고(학생 연락처를 쓰지 않습니다) 이름만 정해 생성
4. CloudShell에서 오류 일으키기:

```bash
for i in $(seq 50); do curl -s -o /dev/null http://로드밸런서주소/error; done
```

## 확인

몇 분 안에 알람 상태가 `OK` 에서 `ALARM` 으로 바뀌고, 오류를 멈추면 다시 `OK` 로 돌아옵니다.

## 막히면

- 계속 `데이터 부족`: 아직 5XX가 한 번도 안 생긴 상태입니다. 오류 요청을 보낸 뒤 1~2분 기다립니다.
